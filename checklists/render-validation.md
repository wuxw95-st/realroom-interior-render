# Render validation checklist

Before delivery, answer every applicable item.

- [ ] Same room envelope and wall geometry as source.
- [ ] Same doors/windows/openings and positions.
- [ ] Same camera viewpoint, perspective and crop unless explicitly changed.
- [ ] No protected furniture/object was removed, moved or redesigned.
- [ ] Requested edit is present.
- [ ] Requested furniture is on the correct wall/corner.
- [ ] Requested furniture orientation/rotation is correct.
- [ ] Furniture scale is compatible with supplied dimensions and room anchor dimensions.
- [ ] Floor/wall/material replacement stays inside the intended surface.
- [ ] Reference furniture/design identity is recognizable where requested.
- [ ] Approved sofa cover/cushion/flooring/wall colors are consistent across angles.
- [ ] Each source angle produced its own separate output.
- [ ] No collage was created unless explicitly requested.
- [ ] No invented architectural feature or unexplained object appears.
- [ ] Result remains photorealistic and physically plausible.

If any hard-constraint item fails, reject the render and regenerate from the original source image rather than patching a structurally incorrect render.
